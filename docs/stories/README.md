# Epics and Stories

Store implementation-ready epics and stories here. A story must contain the user or system outcome, context, acceptance criteria, API changes, event changes, data changes, failure cases, observability, security considerations, test plan, dependencies, and out-of-scope behavior.

Suggested naming: `STORY-NNN-short-title.md`; group larger delivery slices with `EPIC-NNN-short-title.md`.

Identity delivery is grouped in [`EPIC-002-identity-service.md`](EPIC-002-identity-service.md), with stories `STORY-006` through `STORY-013`.
