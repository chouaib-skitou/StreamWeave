# Product Requirements

Store approved product requirements here. A PRD must trace back to [`../brief.md`](../brief.md), define functional and non-functional requirements, identify API/event/data changes, describe failure and security cases, and state out-of-scope behavior.

Suggested naming: `PRD-NNN-short-title.md`.

The Identity Service product requirements are defined in [`PRD-001-identity-service.md`](PRD-001-identity-service.md).

The Gateway Service product requirements are defined in [`PRD-002-gateway-service.md`](PRD-002-gateway-service.md).

The Orders Service product requirements are defined in [`PRD-003-orders-service.md`](PRD-003-orders-service.md).
